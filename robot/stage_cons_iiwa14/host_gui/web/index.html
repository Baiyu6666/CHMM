Demo 采集（Torque）

后台工作站、OptiTrack 和 recorder 常驻运行，不代表拥有机器人控制权。先准备 Demo / Torque，再在 SmartPAD 启动 FRIOverlayGripper 并选择 TORQUE；下方只负责示教、辅助和录制。
从 Planner 切换时会先停止任务、关闭 Position gate、清零旧目标并确认旧 driver 退出，再启动 Torque controller。
Execute 会反向执行同样的 Idle 过渡，因此不需要手动关闭 Demo driver；切换期间不会保留上一次轨迹或辅助状态。
